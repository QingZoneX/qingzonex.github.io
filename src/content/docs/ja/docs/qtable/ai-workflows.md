QTable の AI 機能は手作業と同じ Table / View / Dashboard / Permission モデルを共有します。

典型的な流れ:

```text
目標を書く
   ↓
Workspace / Tables を生成
   ↓
タスクを計画
   ↓
工数とスケジュールを見積もる
   ↓
担当者を提案
   ↓
プロジェクトのリスクを診断
   ↓
アクションをプレビューして適用
```

## Preview → Confirm → Apply

AI のアクションプランは変更プロセスを明示的かつ制御可能に保ちます。

1. AI は現在のユーザーに閲覧権限のあるコンテキストだけを読み取ります。
2. 構造化されたアクションプランを生成します。
3. プレビューは業務データを変更しません。
4. ユーザーは計画の一部だけを確認して受け入れられます。
5. Apply は権限と楽観的／同時実行状態を再検証します。

## プロバイダー設定

現在のコードは OpenAI 互換と DeepSeek 互換の経路をサポートします。API キーはアプリ内の暗号化された AI 設定フローで保存され、ソースコードには入れません。

外部 AI プロバイダーを設定しなくても、中核のテーブル機能は利用できます。
