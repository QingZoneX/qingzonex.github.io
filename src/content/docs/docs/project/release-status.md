QTable and QTableUI currently identify themselves as **`v0.1.0-alpha` — Alpha / Open Source Preview**.

## What this means

The release is suitable for:

- evaluation;
- local/self-hosted testing;
- community development;
- architecture review;
- early integration experiments.

Before v1.0, you should expect some public APIs, behavior and migration paths to evolve.

## Before production adoption

- Read the release notes in both repositories.
- Run the repositories' open-source readiness and test suites.
- Verify database migrations in your environment.
- Replace development credentials and example secrets.
- Configure durable backups for PostgreSQL and object storage.
- Review the current security documentation.

The portal should be updated together with repository release notes whenever the release status changes.
