QingZoneX is opening **QTable** and **QTableUI** as its first open-source release.

- **QTable** is the backend and product-model foundation for AI-native project and work management built on multidimensional tables.
- **QTableUI** is the React frontend that provides Grid, Kanban, Gantt, Calendar, Gallery, dashboards and AI workflow experiences.

Both repositories currently identify themselves as **`v0.1.0-alpha` — Open Source Preview** and declare the **Apache License 2.0**.

## Recommended path

1. Follow the [Quick start](./getting-started/quick-start/) for local development.
2. Read the [QTable architecture](./qtable/architecture/) to understand system boundaries.
3. Review the [security model](./qtable/security/) before exposing a deployment.
4. Use the [QTableUI development guide](./qtable-ui/development/) for frontend work.
5. Check [release status](./project/release-status/) before production adoption.

:::caution[Alpha status]
The current release is suitable for evaluation and community development. Public APIs and migration behavior may still change before v1.0.
:::
