QingZoneX 首次开源范围包含 **QTable** 与 **QTableUI**。

- **QTable** 是基于多维表格构建的 AI 原生项目与工作管理后端及产品模型基础。
- **QTableUI** 是 React 前端，提供 Grid、Kanban、Gantt、Calendar、Gallery、工作中心、仪表盘、自动化、协作与 AI 工作流。

两个仓库当前均标记为 **`v0.1.0-alpha` — Open Source Preview**，并采用 **Apache License 2.0**。

## 推荐阅读路径

1. 按照 [快速开始](./getting-started/quick-start/) 在本地启动系统。
2. 阅读 [QTable 架构](./qtable/architecture/) 理解系统边界。
3. 在对外开放部署前检查 [安全模型](./qtable/security/)。
4. 前端开发请参考 [QTableUI 开发指南](./qtable-ui/development/)。
5. 在生产采用前查看 [发布状态](./project/release-status/)。

:::caution[Alpha 状态]
当前版本适合评估、社区开发和受控试用。v1.0 之前，公开 API 与迁移行为仍可能调整。
:::
