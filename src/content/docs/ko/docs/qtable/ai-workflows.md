QTable의 AI 기능은 수동 작업과 같은 Table / View / Dashboard / Permission 모델을 공유합니다.

일반적인 경로:

```text
목표 설명
   ↓
Workspace / Tables 생성
   ↓
작업 계획
   ↓
공수와 일정 산정
   ↓
담당자 제안
   ↓
프로젝트 리스크 진단
   ↓
액션 미리보기 후 적용
```

## Preview → Confirm → Apply

AI 액션 플랜은 변경 과정을 명시적이고 통제 가능하게 유지합니다.

1. AI는 현재 사용자가 볼 수 있는 컨텍스트만 읽습니다.
2. 구조화된 액션 플랜을 생성합니다.
3. 미리보기는 업무 데이터를 변경하지 않습니다.
4. 사용자는 계획의 일부만 확인해 수용할 수 있습니다.
5. Apply는 권한과 낙관적/동시성 상태를 재검증합니다.

## 공급자 설정

현재 코드는 OpenAI 호환과 DeepSeek 호환 경로를 지원합니다. API 키는 앱 내 암호화된 AI 설정 흐름으로 저장하며 소스 코드에 넣지 않습니다.

외부 AI 공급자를 설정하지 않아도 핵심 테이블 기능은 사용할 수 있습니다.
