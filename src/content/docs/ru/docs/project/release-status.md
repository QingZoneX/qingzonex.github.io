Текущая публичная версия QTable — **`v0.1.1-alpha` — Open Source Preview**.

## Публичный код и тег

Оба репозитория реализации публичны и содержат Git-тег `v0.1.1-alpha`:

- [`QingZoneX/qtable-server`](https://github.com/QingZoneX/qtable-server)
- [`QingZoneX/qtable-web`](https://github.com/QingZoneX/qtable-web)

Вместе они образуют одну продуктовую версию QTable. Фронтенд, API / Domain Services, слой данных и объектное хранилище должны проверяться на одной совместимой базе.

## Состояние артефактов релиза

На данный момент ни в одном репозитории нет опубликованного GitHub Release для `v0.1.1-alpha`. Поэтому **опубликованный Git-тег нельзя трактовать как опубликованный GitHub Release, образ Docker Hub или стабильный артефакт**. Наличие любого образа, Release или другого артефакта зависит от фактических записей публикации соответствующего репозитория.

## Ожидания от Alpha

База подходит для оценки кода, разработки сообществом, staging и контролируемых проб. До v1.0 публичные API, поведение миграций, runbook развёртывания и часть контрактов могут меняться.

Перед прод-развёртыванием пройдите [чек-лист production](../../getting-started/production-checklist/) и прочитайте [матрицу возможностей](../feature-matrix/).
