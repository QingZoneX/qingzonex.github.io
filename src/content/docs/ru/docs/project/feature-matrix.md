## Будущие планы продукта

Работа продолжается по направлениям продукта, а не через привязку портала к конкретным номерам GitHub Issue:

- **Качество релиза и масштабирование**: усиливать сквозную проверку, производительность больших таблиц, стабильность реального времени, адаптивность, доступность, i18n и опыт резервного копирования, восстановления и обновления при самостоятельном хостинге.
- **Открытость и интеграция**: постепенно расширять формы/публичный сбор, API, Webhook, Connector и приём источников, чтобы QTable легче встраивался в существующие системы.
- **Платформа ИИ и автоматизации**: расширять BYO / Self-hosted AI, агентов с учётом прав и оркестрацию автоматизации, сохраняя безопасный путь записи Preview → Confirm → Apply.
- **Экосистема QingZoneX**: будущие рабочие сценарии более высокого уровня переиспользуют структурированные данные, права, совместную работу и автоматизацию QTable, а не строят вторую модель данных.

Это направляющие материалы, а не обязательства по датам; их нельзя описывать как поставленные. Доступные возможности определяются тегом `v0.1.1-alpha`, текущим кодом и реальными артефактами.
