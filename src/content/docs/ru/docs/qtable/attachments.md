Вложения — приватные данные приложения, а не публичные URL объектов.

Ячейки таблиц хранят стабильные метаданные, а не устаревающие URL:

```text
attachmentId + objectKey + name + size + contentType
```

Загрузка, скачивание и удаление идут через авторизованное API QTable с повторной проверкой текущих прав Table и Row.

## Настройка времени выполнения

Текущий контракт хранилища включает:

- `ATTACHMENT_STORAGE_ENABLED`
- `ATTACHMENT_S3_ENDPOINT`
- `ATTACHMENT_S3_ACCESS_KEY`
- `ATTACHMENT_S3_SECRET_KEY`
- `ATTACHMENT_S3_BUCKET`
- `ATTACHMENT_S3_REGION` (необязательно)
- `ATTACHMENT_S3_SECURE`
- `ATTACHMENT_MAX_BYTES`
- настройки пакета/интервала очистки
- `ATTACHMENT_UPLOAD_PENDING_GRACE_SECONDS`

## Жизненный цикл

Записи при мягком удалении сохраняют объекты вложений и поэтому остаются восстанавливаемыми. После постоянной очистки объект попадает в долговременную фоновую очистку. Загрузка создаёт постоянное намерение загрузки до записи в объектное хранилище, поэтому прерванные загрузки можно обнаружить и вернуть.
