---

ИИ-возможности QTable используют ту же модель Table / View / Dashboard / Permission, что и ручная работа.

Типичный путь:

```text
Описать цель
   ↓
Создать Workspace / Tables
   ↓
Спланировать задачи
   ↓
Оценить объём и сроки
   ↓
Предложить ответственных
   ↓
Диагностировать риски проекта
   ↓
Предпросмотреть и применить действия
```

## Preview → Confirm → Apply

План действий ИИ держит процесс изменений явным и управляемым:

1. ИИ читает только контекст, доступный текущему пользователю.
2. Создаёт структурированный план действий.
3. Предпросмотр не изменяет бизнес-данные.
4. Пользователь может принять лишь часть плана.
5. Apply заново проверяет права и оптимистичное/конкурентное состояние.

## Настройка провайдера

Текущий код поддерживает пути, совместимые с OpenAI и DeepSeek. API-ключ сохраняется через зашифрованный процесс настройки ИИ в приложении, а не в исходниках.

Базовые табличные возможности работают и без внешнего ИИ-провайдера.
