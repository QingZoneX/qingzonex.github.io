---
title: قائمة فحص بيئة الإنتاج
description: "الفحوص العملية التي ينبغي تنفيذها عند تقييم نشر QTable v0.1.1-alpha بالاستضافة الذاتية."
---

`v0.1.1-alpha` هو وسم Git لمعاينة مفتوحة المصدر. وقبل كشف QTable لمستخدمين حقيقيين، أكمل الفحوص أدناه في بيئة تطابق بنية الإنتاج.

## الإصدار والمصدر

- [ ] يستخدم `qtable-server` و`qtable-web` وسم `v0.1.1-alpha` المُتحقَّق منه مشتركًا، أو commit محددًا أوضح.
- [ ] عند استخدام Compose من المصدر، يكون المستودعان متجاورين و`QTABLE_UI_CONTEXT=../qtable-web` في `.env`.
- [ ] عند استخدام صور مبنية مسبقًا، تم التأكد من وجود الوسم الهدف فعليًا في Registry وتُسجَّل قيمة digest.
- [ ] لا يُفسَّر «نشر وسم Git» خطأً على أنه «نشر GitHub Release أو منتج إصدار مستقر».

## الإعداد والأسرار

- [ ] `APP_ENV=production`.
- [ ] تغيير `SECRET_KEY` الافتراضي وكلمة مرور قاعدة البيانات وبيانات اعتماد تخزين الكائنات.
- [ ] ضبط Fernet `ENCRYPTION_KEY` ثابت وصحيح التنسيق، مع مشاركة المفتاح نفسه بين النسخ المتعددة.
- [ ] إبقاء OAuth plain PKCE والتسجيل الديناميكي ورمز تصحيح إعادة التعيين مغلقة.
- [ ] عدم دخول مفتاح API الخاص بالمزوّد إلى متغيرات بيئة الواجهة أو حقول الجداول العادية أو السجلات.

## الشبكة وأمان المتصفح

- [ ] كشف مدخل الويب/الوكيل العكسي فقط؛ وإبقاء API وPostgreSQL وRedis وواجهة إدارة MinIO على شبكة خاصة أو عنوان الاسترجاع.
- [ ] ضبط TLS وإعادة التوجيه من HTTP إلى HTTPS وHSTS.
- [ ] التأكد من عدم إضعاف CSP وX-Content-Type-Options وReferrer-Policy وحماية الإطارات وPermissions-Policy في qtable-web بواسطة وكيل خارجي.

## حلقة المنتج

1. سجّل الدخول وتحقق من صلاحيات Workspace / الكائن / الصف.
2. نفّذ فعليًا مسارات قراءة وكتابة تمثيلية في Grid وKanban وGantt وCalendar وGallery.
3. تحقق من تجميع Dashboard والمشاركة العامة وسلوك الوصول بعد تغيّر الصلاحيات.
4. تحقق من رفع/تنزيل المرفقات ومن الرفض بعد فقدان الصلاحية.
5. تحقق من Recycle Bin Restore / Purge.
6. تحقق من قاعدة أتمتة واحدة على الأقل ومن سجل التنفيذ.
7. عند تفعيل الذكاء الاصطناعي، تحقق من Preview → Confirm → Apply وإعادة التحقق من الصلاحيات.
8. نفّذ فعليًا نسخًا احتياطيًا واستعادة واحدة لـ PostgreSQL وتخزين الكائنات على نسخة غير إنتاجية.

يتحسّن دليل النسخ الاحتياطي والاستعادة والترقية في مرحلة Alpha تدريجيًا. وينبغي للنشر الإنتاجي اعتبار تدريب الاستعادة الحقيقي وتثبيت الإصدار والتحقق من التراجع شروطًا مسبقة للإطلاق، لا مجرد التأكد من «وجود ملف نسخ احتياطي».
