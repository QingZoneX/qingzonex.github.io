تتشارك قدرات الذكاء الاصطناعي في QTable نموذج Table / View / Dashboard / Permission نفسه المستخدم في العمل اليدوي.

المسار النموذجي:

```text
وصف الهدف
   ↓
إنشاء Workspace / Tables
   ↓
تخطيط المهام
   ↓
تقدير الجهد والجدول الزمني
   ↓
اقتراح المسؤولين
   ↓
تشخيص مخاطر المشروع
   ↓
معاينة الإجراءات وتطبيقها
```

## Preview → Confirm → Apply

تُبقي خطة إجراء الذكاء الاصطناعي عملية التغيير واضحة وقابلة للتحكم:

1. لا يقرأ الذكاء الاصطناعي إلا السياق المسموح للمستخدم الحالي.
2. ينشئ خطة إجراء مهيكلة.
3. لا تعدّل المعاينة بيانات العمل.
4. يمكن للمستخدم الفحص وقبول جزء من الخطة فقط.
5. يعيد Apply التحقق من الصلاحيات والحالة التفاؤلية/المتزامنة.

## إعداد المزوّد

يدعم الكود الحالي مسارات متوافقة مع OpenAI ومتوافقة مع DeepSeek. ويُحفظ مفتاح API عبر تدفق إعداد الذكاء الاصطناعي المشفّر داخل التطبيق، لا بإيداعه في الكود المصدري.

وتبقى قدرات الجدول الأساسية متاحة دون إعداد مزوّد ذكاء اصطناعي خارجي.
