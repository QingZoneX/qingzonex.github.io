الإصدار العام الحالي من QTable هو **`v0.1.1-alpha` — Open Source Preview**.

## الكود العام والوسم

كلا مستودعي التنفيذ عامان حاليًا، وكلاهما يحتوي على وسم Git باسم `v0.1.1-alpha`:

- [`QingZoneX/qtable-server`](https://github.com/QingZoneX/qtable-server)
- [`QingZoneX/qtable-web`](https://github.com/QingZoneX/qtable-web)

ويشكّلان معًا إصدار منتج QTable واحدًا. ويجب التحقق من الواجهة وAPI / Domain Services وطبقة البيانات وتخزين الكائنات على خط أساس متوافق واحد.

## حالة منتجات الإصدار

حتى الآن، لا يوجد في أي من المستودعين GitHub Release منشور يقابل `v0.1.1-alpha`. ولذلك **لا ينبغي تفسير «نشر وسم Git» على أنه نشر GitHub Release أو صورة Docker Hub أو منتج إصدار مستقر**. ويعتمد وجود أي صورة أو Release أو منتج إصدار آخر على سجلات النشر الفعلية في المستودع المطابق.

## توقعات Alpha

خط الأساس الحالي مناسب لتقييم الكود وتطوير المجتمع وبيئات Staging والتجربة المضبوطة. وقبل v1.0 قد تتغير واجهات API العامة وسلوك الترحيل ودليل النشر وبعض عقود المنتج.

قبل النشر الإنتاجي، أكمل [قائمة فحص بيئة الإنتاج](../../getting-started/production-checklist/) واقرأ [مصفوفة الميزات](../feature-matrix/).
