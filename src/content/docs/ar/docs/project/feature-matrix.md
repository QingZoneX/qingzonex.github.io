تتخذ هذه الصفحة من وسم `v0.1.1-alpha` / قدرات الفرع الرئيسي الحالية في `qtable-server` و`qtable-web` خط أساس، لتجنّب وصف الاتجاهات المخطَّطة كأنها مُسلَّمة.

| Grid / Kanban / Gantt / Calendar / Gallery | منفَّذ | qtable-web + qtable-server |

## خطط المنتج المستقبلية

يستمر العمل وفق اتجاهات منتجية بدل ربط البوابة بأرقام GitHub Issue محددة:

- **جودة الإصدار والتوسّع**: مواصلة تعزيز التحقق الشامل وأداء الجداول الكبيرة واستقرار الزمن الحقيقي واستجابة الواجهة وإمكانية الوصول والتعريب، إضافة إلى تجربة النسخ الاحتياطي والاستعادة والترقية بالاستضافة الذاتية.
- **الانفتاح والتكامل**: توسيع تدريجي لقدرات النماذج/الجمع العام وAPI وWebhook وConnector والمصادر، لتسهيل ربط QTable بأنظمة العمل القائمة.
- **منصّة الذكاء الاصطناعي والأتمتة**: توسيع BYO / Self-hosted AI والوكلاء الواعين بالصلاحيات وتنسيق الأتمتة، مع الالتزام بمسار الكتابة الآمن Preview → Confirm → Apply.
- **منظومة منتجات QingZoneX**: ستُعيد تجارب العمل الأعلى مستوى مستقبلًا استخدام بيانات QTable المنظّمة والصلاحيات والتعاون والأتمتة، بدل بناء نموذج بيانات ثانٍ.

هذه المحتويات اتجاهية ولا تمثّل تواريخ إصدار ملتزمًا بها، ولا ينبغي وصفها كمُسلَّمة. وتبقى القدرات المتاحة فعليًا محدَّدة بوسم `v0.1.1-alpha` والكود الحالي ومنتجات الإصدار الفعلية.
